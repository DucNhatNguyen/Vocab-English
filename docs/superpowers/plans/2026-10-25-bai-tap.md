Emulate 390×844 @2x through CDP `Emulation.setDeviceMetricsOverride` (headless `--window-size` clamps the width and crops). One light walk; dark screenshots only where listed. Never kill the user's dev server on port 5173; stop your own preview server by its PID. Screenshots go to `docs/mockups/exercises/actual/`.
- Do not commit.

## Task 1 — Data and logic (no UI)

1. `src/data/exercises/catalog.ts`: ordered catalog `{ id, title, kind, questionCount, sectionCount }[]` (10 practice tests, 3 grammar, 1 writing) and `loadExerciseSet(id): Promise<ExerciseSet | undefined>` via non-eager `import.meta.glob('./*.json')`. Extend `exercises.test.ts` (it reads files with `node:fs`; keep that) to assert the catalog matches the files (ids, order, counts).
2. `src/lib/exercises.ts` (pure, unit-tested):
   - `sectionInfo(set, section)` → `{ kind: 'vocabulary' | 'reading' | 'completion' | 'cloze' | 'rewrite' | 'grammar', name, meta }`, named as in `detail.png`: reading/cloze use the passage title (fallback "Đọc hiểu (đoạn n)" / "Điền từ"); others use the part after ": " in the title; meta like "Paper 1 · Part A · 10 câu" or "Đọc hiểu · Part B · 5 câu". Writing sections use their title and "n câu".
   - `flattenQuestions(set, sectionId?)` with each question's section.
   - `normalizeRewrite(text)` and `isRewriteCorrect(input, question)` per spec §3.4 (lowercase, collapse spaces, curly → straight quotes, drop final punctuation, no space before punctuation, expand n't/'m/'re/'ve/'ll/can't/won't; not 's/'d). Compare `prefix + input + suffix` against `prefix + answer + suffix` for every accepted answer. Test against real questions from the data, including suffix cases (`writing-practice.json` wp01 q3/q5, wp10 q4; pt06 q49).
3. Dexie version 2 (`src/db/db.ts`, `types.ts`): tables `exerciseAttempts` and `exerciseResults` per spec §4.3. `src/db/exercises.ts` with tests (fake-indexeddb, like the other db tests):
   - `startOrResumeAttempt(setId, sectionId?)`, `restartAttempt(...)`, `getOpenAttempt(setId, sectionId?)`;
   - `recordAnswer(attemptId | null, setId, questionId, answer)`: writes the attempt (if any) and the latest result;
   - `finishAttempt(id)`;
   - `getExerciseOverview()` for the tab: per-set status per the spec's priority rules, latest open attempt for "Đang làm dở", wrong count and number of sets with wrong answers;
   - `getSetProgress(setId)` for the detail: best full score, last full score, finished full-attempt count, per-section correct count from results;
   - `getWrongQuestionIds(setId?)`.
4. Backup (`src/lib/backup.ts`, `src/db/backup.ts`): include both tables, bump `formatVersion`, still accept the previous version (missing tables = empty), drop records whose `setId` is not in the catalog. Extend the backup tests.

Acceptance: all new logic covered by unit tests; existing tests untouched and green.

## Task 3 — Session, question types, summary

- `src/pages/exercises/ExerciseRun.tsx` for the run routes and the retry route:
  - Starting a scope that has an open attempt asks "Làm tiếp" / "Làm lại từ đầu".
  - Each answer is saved immediately with `recordAnswer`.
  - The exit confirm says progress is saved.
  - Retry runs create no attempt and only update results.
- Question views, matching the targets:
  - **Choice** (`choice-wrong.png`): `___` rendered as a gap line; red-pen feedback; explanation card with "Vì sao “x” sai:" from `optionNotes`.
  - **Reading** (`reading.png`): passage card clamped (~8 lines, fade mask) with "Đọc cả bài" / "Thu gọn"; the expanded state persists across that passage's questions; the question number is shown in accent colour.
  - **Cloze** (`cloze.png`):
    - Blanks render inside the passage card, which scrolls internally (max-height ~320px); the current blank is highlighted and scrolled into view.
    - Answered blanks show the chosen word: green when right; when wrong, struck through with the right word next to it.
    - The four options are shown as a 2×2 grid.
  - **Rewrite** (`rewrite-wrong.png`):
    - Shows the source sentence card, then the prefix, a textarea (≥16px font) and the suffix. Join prefix + answer + suffix without a space before punctuation.
    - "Kiểm tra" is disabled while the input is empty.
    - Correct answer: green tick, "Đúng rồi!" and the explanation.
    - Wrong answer: the attempt is struck line by line, `answers[0]` is handwritten below, and the explanation card shows "Cũng đúng: …" when there are other accepted answers.
    - Footer: "Mình viết đúng" (marks `selfMarked`, flips the verdict to correct, then hides) and "Tiếp".
  - Writing sections show their `examples` in a collapsible card at the start of the section.
  - The kicker above each question shows the section (e.g. "Paper 2 · Điền từ vào đoạn văn").
- Summary (`summary.png`):
  - Score hero (trophy badge; "Cao nhất từ trước tới nay" when it is a new best; count of self-marked answers).
  - "Theo từng phần" rows with meters.
  - "Câu sai · n" rows; tapping one opens a read-only review of that question with answer and explanation.
  - Footer: "Xong" (back to detail or to the list after a retry) and "Làm lại câu sai" (a retry of this run's wrong questions; hidden when there are none).
- Browser walk: answer a few questions of practice-test-01 (vocabulary wrong + right, reading with expand, cloze, rewrite wrong + "Mình viết đúng"), exit and resume from the list, finish a section, open the summary, run "Làm lại câu sai". Screenshots in `actual/`: `choice-wrong`, `reading`, `cloze`, `rewrite-wrong`, `summary`, `summary-dark`. Compare with the targets and fix material mismatches.
